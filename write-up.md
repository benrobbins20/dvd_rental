# DVD Rental adult-rated film analysis

#### Recent studies regarding the habits of adults have shown that the DVD rental industry is seeing a surge of poeple renting  films on disk, particularly with 'R' and 'NC-17'. To bolster these new trends, the business decision to increase the inventory of adult rated films and increase revenue is being made. 

#### The special conditions for the analysis include the following:
- Get store with highest amount of adult films
- Get the top 200 films with longest rental duration
- display the increased inventory count and the revenue potential of adding the extra films

### **A1-A2**: Detailed and Summary Tables, including data types used
--------
#### Detailed table
- film_id INT PRIMARY KEY -- unique id for each film
- film_rating VARCHAR(5) -- mpaa_rating casted to VARCHAR
- film_title VARCHAR(255) -- title of film
- film_description TEXT -- No limit to text, best for long string descriptions
- rental_price NUMERIC -- dollar amount 4.99
- inventory_count INT -- COUNT(*) of all the same film_id's tied to multiple rental records
- store_id INT -- store_id
- rental_duration DOUBLE PRECISION -- return-rental (epoch seconds) / 3600 = hours. 

#### Summary table

- film_id INT PRIMARY KEY
- film_title VARCHAR(255) 
- film_rating VARCHAR(10)
- increased_inventory VARCHAR(255) -- inventory count is increased by a percentage
- revenue_potential NUMERIC -- revenue potential is dollar amount of the rental_rate * added inventory_count
-----------

### **A3**: Tables pulled from the dvdrental database
#### public.film
- film_id, film_rating, film_title, film_description: Basic film information
#### public.inventory
- inventory_count: COUNT(*) performed on the amount of film_ids across 
- store_id: Helper function most_adult_film_rentals() retieves the store with the most adult film rentals
#### public.rental
- rental_data, return_date: Used to caluclate the confirmed duration of the rental
#### custom columns
- increased_inventory: Calculated by the function increase_adult_film_inventory() which takes the current inventory count and increases it by a percentage
- revenue_potential: Product of the rental_price and the count that was added to inventory

### **A4**: Fields requiring transformation
- increased_inventory: COUNT(*) aggregation of the film_id is modified by increases the inventory count by a percentage, in this case 30%. EG: $count * (1 + percent / 100.0)$
- revenue_potential: An added column in the summary table which uses the rate of the rental and displays amount of additional reveneue that could be generated with the added count.

### **A5**: Use cases for the new tables generated by ths business analysis
- **Detailed Adult Films**: This table provides a comprehensive view of adult-rated films, including their titles, descriptions, and rental prices. Also, for validation, the store_id confirms that only the store with most vilume of adult films is considered for the inventory modifications.
- **Summary Adult Films**: The summary table includes the difference between the added films and the original inventory. It shows the film_id and title, along with the increased revenue per film.
